# M0D — Message Over Distance

<p align="center">
  <img src="assets/logo.svg" alt="M0D" width="420">
</p>

**M0D** — мессенджер для личного общения на расстоянии.

Проект развивается как отдельный мессенджер с привычной структурой: личные чаты, группы, каналы, медиа, голосовые и видеозвонки. Интерфейс ориентируется на удобство современных мессенджеров, но использует собственный стиль и бренд M0D.

> Проект находится в активной разработке. Интерфейс и часть функций ещё меняются.

## Возможности

- личные чаты;
- группы и каналы;
- ответы, реакции, редактирование и удаление сообщений;
- фото, видео и файлы;
- закреплённые сообщения;
- комментарии к постам каналов;
- username и ссылки на чаты;
- голосовые и видеозвонки;
- история звонков;
- уведомления;
- Android-приложение;
- приложение для Windows 10/11;
- встроенные обновления Android и Windows;
- PWA для браузера;
- русский, английский и украинский интерфейс.

## Платформы

Сейчас M0D развивается для:

- Web / PWA;
- Android;
- Windows 10/11 (x64).

## Статус

M0D пока находится в разработке. Основные направления работы:

- стабильность голосовых и видеозвонков;
- работа звонков в фоне на Android;
- уведомления;
- мобильный интерфейс;
- улучшение качества связи;
- доработка групп, каналов и профилей.
